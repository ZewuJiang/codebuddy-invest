蒸馏能传什么，不能传什么

  • 能高效迁移：教师"已经会做"的题的解法分布、输出风格、工具调用轨迹、对齐格式。这正是蒸馏模型能在已知任务类型上快速逼近甚至超越榜分的原因——所以"啥都没学到"是夸大的。
  • 无法迁移：产生新能力的机器——RL 探索、可验证奖励、self-play，在没有教师答案的问题上自己"想出"解法。蒸馏本质是模仿已存在的答案分布，永远无法蒸出教师还不会的东西。
正确表述 真实差距 不是"今天做题分数"的代差（那个已很小、局部反超），而是"谁能把能力边界往前推"的 leader–follower 代差。文档"没掌握内功心法"的比喻，用在原创前沿能力上是对的，用在当下任务表现上是夸大的。

需强调：把整个"国模"打包成"全是蒸馏"是以偏概全。DeepSeek 在 R1 路线上以纯 RL（GRPO、无人工标注推理链）实证了原创推理训练能力 ⑤，这与"月之暗面走极端蒸馏+刷榜"是两条不同的路——文档自身也承认"DS 相对最强、有真·自研内测版"。

07前沿模型真正的护城河

Fable 5 / GPT-5.6 Sol 难追，护城河不在模型大小，而在"能力生产线"：

  1. RL 基础设施与环境（最核心）：可验证奖励（数学/代码/工具执行）、大规模 agentic RL、self-play 与自动化环境构建——这是"从没有标准答案的问题里长出新能力"的引擎。若"月之暗面裁 RL 组、退回 SFT→SFT"属实，这才是它注定当追随者的根因，与参数量无关。
  2. 数据飞轮：真实用户 + 真实 agent 轨迹的闭环。蒸馏者只能拿到教师的"输出快照"，拿不到"教师如何在真实反馈中迭代"。
  3. 预训练数据质量与计算效率：优势越来越体现在同等算力下的效率，而非绝对规模（文档提到的"数据效率数倍/Looped Transformer"虽未证实，方向对）。
  4. 原创推理链的生成能力：即"内功心法"。蒸馏能拿到教师这一代的 CoT 快照，拿不到生成下一代 CoT 的方法。

08蒸馏的结构性天花板

最值得提炼的技术要义 蒸馏是"导数"，不是"函数本身"。学生模型的能力上界 = 教师当前能力（现实中还因信息损耗略低于教师）。你永远滞后至少一代，且结构上无法超越教师。

文档那句黑色幽默——"等 Anthropic 发 Fable 5.1，糊几个架构改进、发几篇论文拖时间，蒸蒸日上"——技术上是精准的：只要能力来源是别人的输出，你的天花板就被别人的发布节奏钉死。

所以"鸿沟到底多大"的最终答案分两个面：

  • 在"今天能做的任务"截面上：鸿沟正快速缩小，个别领域已抹平/反超——但其中一部分是刷榜与路由造出来的"分数"，不是"能力"（文档此点说得对：刷的是 coding 分数，不是 coding 能力）。
  • 在"能不能自己往前走"的导数上：鸿沟是结构性、代差级的，且只要走纯蒸馏路线，它不会因参数变大而缩小。真正能缩小它的，只有 DeepSeek/Qwen 那种重建自研 RL 与数据飞轮的路线。

09总研判

最终定论 文档事件为真、机制半真、归因夸张。国模与前沿的真实差距，不在参数量（该轴中国开源反而更大），而在能力生产线——RL 环境、数据飞轮、原创推理链生成。蒸馏让国模在静态任务截面贴近前沿、局部反超（掺刷榜水分），却让极端蒸馏路线者背上结构性天花板：永远滞后一代、无法超越教师。"接近 Fable 5"这句话，在跑分上越来越真，在能力本源上仍隔着一道由训练范式（而非模型尺寸）决定的鸿沟。
